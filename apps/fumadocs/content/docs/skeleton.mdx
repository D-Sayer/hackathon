`Skeleton` is the shared loading placeholder. It helps the layout stay stable while content is pending and gives the user a clear sense that data is on the way.

## When to use it

- Use it for lists, cards, media blocks, and text lines that are still loading.
- Match the placeholder shape to the final content as closely as possible.
- Keep the skeleton visible only while the actual content is unavailable.

## Usage guidance

- Avoid placing skeletons where the final content will shift dramatically in height.
- Use a small set of placeholder shapes consistently across the app.
