---
title: Toaster
description: Theme-aware global toast host for Sonner notifications.
---

`Toaster` mounts the shared toast surface used for transient notifications. It reads the current theme from `next-themes`, so the notification styling stays aligned with the rest of the app shell.

## When to use it

- Render it once near the root of the application.
- Drive notifications from application code, not from the toaster component itself.
- Keep it out of individual pages so every route shares one consistent toast stack.
