# Hackathon UI

Hackathon UI documents the shared components used across this workspace. The site now covers the reusable primitives, grouped controls, and overlay patterns that show up across product surfaces.

## What lives here

- `Button` defines emphasis, intent, and action hierarchy.
- `Card` groups related content into flexible, composable containers.
- `Input`, `Textarea`, `Checkbox`, `Switch`, and `RadioGroup` cover the common form controls.
- `DropdownMenu`, `AlertDialog`, and `ButtonGroup` handle compact command and confirmation flows.
- `Field`, `InputGroup`, `Item`, `Badge`, `Skeleton`, `Separator`, and `Toaster` cover the shared structure and feedback helpers.

<Guidance title="Scope">
  These docs are intentionally focused on the components that are already shared
  across the monorepo. The goal is implementation clarity, not a catalog of
  unfinished ideas.
</Guidance>

## Principles

- Use the shared package as the source of truth rather than duplicating ad hoc component recipes in apps.
- Prefer a small number of clear variants over one-off custom styling in product code.
- Document composition patterns, not just prop names, so contributors can build consistent screens faster.
