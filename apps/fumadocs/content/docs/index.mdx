# Hackathon UI

Hackathon UI documents the shared components used across this workspace. This site intentionally starts narrow: it covers the interaction control we use most often and the surface container that organizes most product layouts.

## What lives here

- `Button` defines emphasis, intent, and action hierarchy.
- `Card` groups related content into flexible, composable containers.

<Guidance title="Scope">
  These docs are intentionally limited to Button and Card. The goal is depth and implementation clarity, not a broad catalog of unfinished components.
</Guidance>

## Principles

- Use the shared package as the source of truth rather than duplicating ad hoc component recipes in apps.
- Prefer a small number of clear variants over one-off custom styling in product code.
- Document composition patterns, not just prop names, so contributors can build consistent screens faster.
