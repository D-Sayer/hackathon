## Components Overview

This section documents the reusable UI components available in the shared `@hackathon/ui` package.

Each component page includes:

- Installation and import guidance
- Practical usage examples
- Styling and customization notes
- API reference details

---

## Available Components

- **Button** – Interactive button component with consistent variants and states.
- **Kbd** – Display keyboard keys and shortcuts using semantic `<kbd>` markup.

Select a component from the sidebar to view detailed documentation and examples.

As new primitives and higher-level components are added to the UI package, they will be documented here following the same structure and conventions.
