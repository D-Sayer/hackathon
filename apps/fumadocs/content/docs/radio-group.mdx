`RadioGroup` is the standard control for one-of-many choices. It should be used when the user must select a single option from a small set and the choices belong to the same question.

## When to use it

- Use it for plan selection, preferences, and mutually exclusive settings.
- Keep the labels adjacent to the radio so the option reads as one unit.
- Prefer radios over a select when the choices are short and should remain visible.

## Usage guidance

### Choice design

- Keep each label short and parallel in phrasing.
- If the choices need descriptions, place the copy beside or under the radio.
- Use a default selection only when it is genuinely the best starting point.

### Accessibility

- Give the group a shared label or legend.
- Make sure the active state is obvious at a glance, not just via focus.
