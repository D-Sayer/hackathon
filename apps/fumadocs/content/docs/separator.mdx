`Separator` provides a simple rule for breaking up groups of content. It is intentionally quiet so it helps the layout read clearly without becoming a visual feature on its own.

## When to use it

- Use it to divide groups, sections, or adjacent controls.
- Use vertical separators for inline clusters such as toolbars or compact metadata rows.
- Prefer the semantic separator over an arbitrary border class when the structure matters.

## Usage guidance
