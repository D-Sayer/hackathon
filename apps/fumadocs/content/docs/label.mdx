`Label` is the basic text caption used to identify a control. It should describe the adjacent input or toggle in plain language and stay close enough that the relationship is obvious.

## When to use it

- Use it for form fields, checkbox rows, and switch rows.
- Keep labels concise and action-oriented where possible.
- Match the label text to the wording the user will see elsewhere in the flow.

## Usage guidance

- Connect the label with `htmlFor` whenever the control uses an `id`.
- Avoid writing a label that duplicates the surrounding section heading.
- Treat the label as the primary accessible name for the control.
