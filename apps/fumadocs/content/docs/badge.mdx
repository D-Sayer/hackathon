`Badge` is the shared chip-style label for statuses, categories, and quick metadata. It is intentionally small so it can sit inline with text, buttons, or other compact UI.

## When to use it

- Use it for short state labels such as `Draft`, `Live`, or `Beta`.
- Pair it with text or icons when the meaning needs a little more context.
- Use `variant="destructive"` only when the status itself is negative or urgent.

## Usage guidance

- Keep badge text short and scannable.
- Avoid using badges as standalone navigation or action controls unless they are rendered as links or buttons on purpose.
- Use a small set of variants consistently so the same color always means the same thing.
