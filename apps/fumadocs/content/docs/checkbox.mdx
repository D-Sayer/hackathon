`Checkbox` is the shared selection primitive for yes/no states and multi-select forms. It works best when the choice is independent from the other controls around it.

## When to use it

- Use it for consent, filters, and any setting that can be toggled independently.
- Pair it with a `Label` so the target and the text read as one control.
- Use the mixed state only when the selection is partially applied at a group level.

## Usage guidance

- Always provide an accessible name.
- Keep related checkboxes close together and explain any dependencies nearby.
- Prefer radios if the user can choose only one option from the set.
