`Input` is the default text field for most forms. It handles the common single-line cases and keeps validation, focus, and disabled styling consistent across the workspace.

## When to use it

- Use it for names, emails, search terms, codes, and short free-form text.
- Pair it with `Label` and helper text when the field needs extra explanation.
- Use `type` to opt into the right browser keyboard and validation behavior.

## Usage guidance

- Keep placeholder text short and descriptive.
- Use the right `type` to get native affordances like email keyboards and search controls.
- Do not use the input as a stand-in for a multi-line prompt; use `Textarea` instead.
