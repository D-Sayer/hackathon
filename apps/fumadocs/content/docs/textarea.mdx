`Textarea` is the shared multiline control for longer text entry. It preserves the same focus, validation, and disabled styling as the single-line input while giving the user room to write.

## When to use it

- Use it for comments, descriptions, feedback, and other longer responses.
- Pair it with guidance when you expect a minimum length or a specific format.
- Use it instead of `Input` whenever the expected response may span multiple lines.
