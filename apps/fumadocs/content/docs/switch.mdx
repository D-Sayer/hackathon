`Switch` is the compact on/off control for settings that can be changed in place. It works well for preferences because the current state is visible without opening another control.

## When to use it

- Use it for binary settings, notifications, and feature toggles.
- Pair it with a label so the state is clear without extra explanation.
- Use `size="sm"` when the switch needs to fit into denser forms or tables.

## Usage guidance

- Keep the label phrased as an action or setting state, not a vague instruction.
- Avoid using switches for actions that need confirmation or delayed execution.
